# Limitless Notes — MEAN-like App (React + MUI, Node + Express, MongoDB)

## Quick start (development)

0. Prerequisites:
   - Node.js >= 18
   - npm
   - MongoDB running locally or a connection URI

1. Clone / create project, copy files.

2. Install dependencies:

```bash
# root (install concurrently)
npm install

# server
cd server
npm install

# client
cd ../client
npm install
