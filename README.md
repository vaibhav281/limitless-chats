# Limitless Chats

An end-to-end encrypted real-time chat application built using modern web technologies.

## 🚀 Features
- Signal Protocol based E2EE
- Secure File Encryption (AES-GCM)
- Real-time messaging
- Secure key exchange
- Industry-standard architecture

## 🛠 Tech Stack
**Frontend:**
- React.js
- Vite
- Axios

**Backend:**
- Node.js
- Express
- MongoDB

## 🔐 Security
- Double Ratchet encryption
- AES-GCM file encryption
- Zero-knowledge server storage

## 📦 Installation
```bash
npm install
npm run dev
```
